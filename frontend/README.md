# Frontend – NYC Taxi Analytics Dashboard

## Overview

This is the React + Vite + TypeScript frontend for the NYC Taxi Analytics project.
It provides interactive visualizations and controls for exploring taxi trip data, economic metrics, temporal trends, and geospatial patterns.

## Getting started

### Prerequisites

- Node.js (LTS recommended) and npm  
  - Install via nvm: see the [nvm docs](https://github.com/nvm-sh/nvm#installing-and-updating)

### Setup

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the frontend directory
cd frontend

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

By default, the app runs on `http://localhost:5173` (or the port Vite chooses).

## Tech stack

This project uses:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Building for production

```sh
npm run build
```

The production build will be output to the `dist` directory.

## Linting

```sh
npm run lint
```

Run this before committing changes to keep code quality consistent.
